# Дизайн-план CRM4Retail (по скиллу frontend-design)

## Бриф
Продукт: CRM для розницы. Аудитория: владельцы магазинов, сетей, франшиз (не технари). Работа страницы: привести к заявке «Получить демо». Стиль из ТЗ: digital, минимализм, IT-эстетика.

## Язык дизайна: кассовый чек
Самый характерный предмет в мире розницы — чек и ценник. Отсюда: чековая лента с зигзагом как hero-элемент, строки прайса с точечными выносками вместо карточек, моноширинные цифры как «печать кассы», красный штамп вместо бейджей.

## Токены
| Токен | Значение | Роль |
|---|---|---|
| paper | #F7F4EC | фон, бумага чека |
| ink | #191D23 | текст, тёмная CTA-панель |
| muted | #5B616B | вторичный текст |
| hairline | #E5E0D5 | линейки, разделители |
| stamp | #D92D20 | единственный акцент: цены, штамп, CTA |
| till | #067647 | только позитивные метрики |

Типографика: Inter (заголовки + текст, tight), моно (ui-monospace — цифры, чек, данные). Две семьи, роли не пересекаются.
Раскладка: левое выравнивание, «гроссбух»; контент 1200px, поля 120px при 1440.

## Принципы
1. Один запоминающийся элемент — чек. Всё остальное молчит.
2. Красный — только цена/штамп/CTA. Моно — только данные.
3. Номера 01–04 только в «Как это работает» (это последовательность). В функциях номеров нет.
4. Без карточного набора, без eyebrow-лейблов капсом, без градиентных заливок, без «→» в кнопках.

## Что пересмотрено (самокритика)
- Первый порыв: тёмный hero + кислотный акцент → отброшен, это дефолт №2 из скилла и спорит с «бумажной» идеей.
- Первый порыв: 4 функции одинаковыми карточками → заменены строками прайса с выносками, информативнее и не «SaaS-кит».
- Акцент на одном слове в H1 → убран, заголовок цельный.

## SVG-набор (design/svg/)
- 01-hero.svg — hero 1440×640
- 02-features.svg — функции строками прайса 1440×520
- 03-steps.svg — 4 шага 1440×480
- 04-cta.svg — тёмная CTA-панель с формой 1440×580

Текст в SVG — живым <text> (Inter/monospace), после импорта в Figma правится как обычный текст. Заглушки под замену данными заказчика: телефоны, тарифы, цифры кейсов.

## Импорт в Figma (без MCP, работает сейчас)
Вариант 1 — drag-and-drop: перетащить .svg файлы на канвас Figma (или File → Place image → выбрать SVG). Каждый станет редактируемым фреймом.
Вариант 2 — через MCP (когда завершишь `opencode mcp auth figma` и перезапустишь сессию): импортировать строкой SVG через `figma.createNodeFromSvg(svgString)` — соберу скрипт под твой fileKey.

## Качество
- Контраст ink/paper ≈ 15:1, stamp/paper ≈ 4.6:1 (крупный текст и CTA).
- Русская типографика: «ёлки», … (многоточие символом), &nbsp; перед «в/на» в заголовках при вёрстке.
- Мобильная адаптация и reduced-motion — на этапе вёрстки.
